# 00. 프로젝트 선정 배경

## 1. 프로젝트 개요

Flex-log는 사용자가 자신의 소비를 SNS 방식으로 기록하고, 기록된 소비 데이터를 분석하여 소비 습관 개선방안을 제공하는 금융 웹 애플리케이션이다.

본 프로젝트는 단순한 가계부 서비스가 아니라, 젊은 세대가 소비를 쉽고 재미있게 기록할 수 있도록 돕고, 이를 바탕으로 자신의 소비 패턴을 인식하도록 하는 것을 목표로 한다.

핵심 흐름은 다음과 같다.

```text
소비 기록 → 소비 분석 → 개선방안 제시
```

---

## 2. 프로젝트 선정 배경

프로젝트 주제를 선정하기 위해 먼저 젊은 세대가 겪는 소비 관련 문제를 중심으로 회의를 진행하였다.

최근 젊은 세대는 SNS, 온라인 쇼핑, 배달 서비스, 구독 서비스 등 다양한 소비 환경에 쉽게 노출되어 있다. 소비 기회는 많아졌지만, 본인이 실제로 어떤 항목에 얼마를 사용하고 있는지 명확하게 인식하지 못하는 경우가 많다.

또한 SNS를 통해 타인의 소비 생활을 쉽게 접하면서 소비 욕구가 자극되거나 상대적 박탈감을 느끼는 경우도 있다. 여기에 물가 상승까지 더해지면서 소비 관리의 필요성은 커지고 있지만, 소비를 꾸준히 기록하는 습관을 가진 사용자는 많지 않다.

기존 가계부 서비스는 금액과 카테고리를 직접 입력하는 방식이 중심이기 때문에, 사용자가 흥미를 느끼기 어렵고 지속적으로 사용하기 어렵다는 한계가 있다고 판단하였다.

이러한 문제의식을 바탕으로 Flex-log는 사용자가 자신의 소비를 부담 없이 기록하고, 기록된 데이터를 통해 소비 습관을 개선할 수 있도록 돕는 서비스로 기획되었다.

## 3. 주제 선정을 위해 활용한 기법

프로젝트 주제를 선정하는 과정에서는 다음과 같은 기법을 활용하였다.

| 기법            | 활용 내용                          | 도출 결과                                                            |
| ------------- | ------------------------------ | ---------------------------------------------------------------- |
| 브레인스토밍        | 젊은 세대의 소비 문제를 자유롭게 나열          | 소비 증가, 금융 지식 부족, 무분별한 소비 습관, SNS 영향 등의 문제 도출                     |
| 요구사항 도출       | 사용자가 실제로 필요로 하는 기능을 문제 상황에서 추출 | 소비 기록, 소비 분석, 개선방안 제시 기능 필요                                      |
| 프로토타이핑 관점     | 사용자가 서비스를 어떻게 이용할지 흐름을 가정      | 소비 로그 작성 → 피드 확인 → 분석 확인 → 피드백 확인 흐름 도출                          |
| 유스케이스 분석      | 사용자가 시스템에서 수행할 행동을 정리          | 회원가입, 로그인, 소비 로그 작성, 친구 로그 조회, 좋아요, 댓글, 프로필 관리 도출                |
| 데이터 구조 분석     | 서비스에 필요한 주요 데이터를 정리            | User, Profile, Friend, ExpenseLog, Category, Like, Comment 구조 도출 |
| HIPO 관점 기능 분해 | 전체 서비스를 큰 기능 단위로 분리            | 회원, 프로필, 소비 로그, 친구, 반응, 분석 기능으로 분해                               |

## 4. 브레인스토밍 과정

회의에서는 금융 프로젝트의 방향을 정하기 위해 젊은 세대의 소비 문제를 중심으로 브레인스토밍을 진행하였다.

도출된 의견은 다음과 같다.

* 젊은 세대의 소비가 많다.
* 경제적인 노하우나 금융 지식이 부족하다.
* 소비 습관이 무분별하게 형성되기 쉽다.
* 물가가 높아 체감 지출 부담이 크다.
* SNS로 인해 소비 생활이 촉진된다.
* SNS를 통해 상대적 박탈감을 느낄 수 있다.
* 본인이 한 달에 얼마를 쓰는지 정확히 모르는 경우가 많다.
* 소비를 꾸준히 기록하는 습관이 부족하다.

브레인스토밍을 통해 단순히 “소비가 많다”는 것이 문제가 아니라, 사용자가 자신의 소비를 인식하고 관리하는 습관이 부족하다는 점이 핵심 문제라고 판단하였다.

---

## 5. 문제 정의

브레인스토밍 결과를 바탕으로 핵심 문제를 다음과 같이 정의하였다.

> 젊은 세대는 소비 기회가 많고 SNS의 영향을 쉽게 받지만, 자신의 소비를 꾸준히 기록하고 분석하는 습관이 부족하다.

이 문제는 다음과 같은 세부 문제로 나눌 수 있다.

| 문제             | 설명                                 |
| -------------- | ---------------------------------- |
| 소비 인식 부족       | 본인이 한 달에 얼마를 쓰는지 정확히 알지 못함         |
| 기록 습관 부족       | 가계부를 꾸준히 작성하지 못함                   |
| 소비 자극 환경       | SNS와 주변 소비 문화로 인해 소비 욕구가 커짐        |
| 금융 지식 부족       | 소비를 관리하거나 개선하는 방법을 잘 모름            |
| 기존 서비스의 지속성 부족 | 기존 가계부 서비스는 입력 방식이 딱딱하고 재미 요소가 부족함 |

---

## 6. 해결 방향 도출

문제 정의 이후, 해결 방향을 다음과 같이 정리하였다.

| 문제                 | 해결 방향                    |
| ------------------ | ------------------------ |
| 소비를 꾸준히 기록하지 않음    | SNS 방식의 소비 로그 기능 제공      |
| 본인의 소비 규모를 인식하지 못함 | 월별 소비 금액과 카테고리별 소비 분석 제공 |
| 기존 가계부가 재미없음       | 이미지 기반 피드 형태로 소비 기록 작성   |
| 소비 습관 개선 방향을 모름    | AI 또는 규칙 기반 소비 피드백 제공    |
| 소비 기록이 민감할 수 있음    | 친구 관계인 사용자에게만 로그 공개      |

이를 바탕으로 Flex-log의 핵심 기능은 다음과 같이 정리되었다.

```text
1. SNS 방식으로 소비 기록
2. 기록된 소비 데이터를 분석
3. 소비 습관 개선방안 제시
```

---

## 7. 서비스 핵심 개념

Flex-log의 핵심 개념은 다음 두 가지이다.

## 7.1 기록

Flex-log는 소비 기록을 기존 가계부처럼 숫자 중심으로만 입력하는 것이 아니라, SNS 피드처럼 이미지와 텍스트를 함께 기록하는 방식으로 설계하였다.

사용자는 소비 금액, 카테고리, 이미지 또는 영상, 간단한 텍스트를 함께 작성할 수 있다.

이를 통해 소비 기록의 진입 장벽을 낮추고, 젊은 세대가 더 자연스럽게 소비를 기록할 수 있도록 한다.

---

## 7.2 소비 습관 개선방안

소비 로그는 단순히 기록으로 끝나는 것이 아니라, 소비 분석의 기준 데이터로 활용된다.

사용자의 소비 금액과 카테고리를 기반으로 월별 소비 금액, 카테고리별 소비 비율, 소비 패턴을 분석한다.

이후 AI 분석 또는 규칙 기반 분석을 통해 사용자에게 소비 습관 개선방안을 제시한다.

예시는 다음과 같다.

```text
- 식비 비중이 높을 경우 식비 절약 피드백 제공
- 카페 소비가 잦을 경우 카페 소비 조절 피드백 제공
- 쇼핑 소비가 전월 대비 증가한 경우 충동구매 주의 피드백 제공
```

## 8. 최종 주제 선정 결과

회의와 기법 적용 결과, 최종 프로젝트 주제는 다음과 같이 선정하였다.

> SNS 방식의 소비 기록을 기반으로 사용자의 소비 습관을 분석하고 개선방안을 제시하는 금융 웹 애플리케이션

서비스명은 Flex-log로 정하였다.

Flex-log는 소비를 과시한다는 의미의 “Flex”와 기록을 의미하는 “Log”를 결합한 이름이다.
즉, 사용자의 소비를 기록하고 돌아보게 한다는 의미를 담고 있다.

---

## 9. 기대 효과

Flex-log를 통해 기대하는 효과는 다음과 같다.

* 젊은 세대가 친숙한 SNS 방식으로 소비를 기록할 수 있다.
* 소비 기록에 대한 심리적 부담을 줄일 수 있다.
* 사용자의 자발적인 소비 기록 습관을 촉진할 수 있다.
* 소비 로그가 누적되면서 개인 소비 데이터를 확보할 수 있다.
* 사용자는 자신의 월별 소비와 카테고리별 소비 패턴을 확인할 수 있다.
* 분석 결과를 통해 소비 습관 개선방안을 확인할 수 있다.
* 장기적으로 사용자가 자신의 소비를 인식하고 관리하는 습관을 형성할 수 있다.

## 11. 정리

Flex-log는 젊은 세대의 소비 습관 문제를 해결하기 위해 기획된 금융 웹 애플리케이션이다.

프로젝트 초기에는 브레인스토밍을 통해 젊은 세대의 소비 문제를 자유롭게 도출하였고, 이후 요구사항 도출, 유스케이스 분석, 데이터 구조 분석, HIPO 관점의 기능 분해를 통해 서비스의 핵심 기능을 정리하였다.

그 결과 Flex-log는 단순한 가계부가 아니라, SNS 방식으로 소비를 기록하고, 기록된 소비 데이터를 분석하여 소비 습관 개선방안을 제시하는 서비스로 방향이 정해졌다.

핵심 가치는 다음과 같다.

```text
재미있게 기록하고, 데이터로 돌아보고, 소비 습관을 개선한다.
```

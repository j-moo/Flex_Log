# 01. 요구사항 정의 수정 사항

## 1. 핵심 기능 방향 수정

Flex-log의 핵심 기능은 단순 소비 기록과 기본 분석에 그치지 않고, AI 분석과 금융상품 추천까지 연결되는 구조로 수정한다.

기존 핵심 흐름은 다음과 같았다.

```text
소비 기록 → 소비 분석 → 개선방안 제시
```

회의 결과, 금융 프로젝트의 성격을 더 명확히 하기 위해 핵심 흐름을 다음과 같이 수정한다.

```text
소비 기록 → AI 소비 분석 → 금융상품 추천
```

즉, 사용자가 작성한 소비 로그를 기반으로 소비 패턴을 분석하고, AI를 활용하여 소비 습관에 대한 피드백을 제공한다. 이후 외부 금융상품 API를 활용하여 사용자의 소비 습관에 적합한 금융상품을 추천하는 것을 필수 기능으로 포함한다.

## 2. 수정된 서비스 핵심 목표

Flex-log의 핵심 목표는 다음과 같다.

| 목표          | 설명                                          |
| ----------- | ------------------------------------------- |
| 소비 기록 습관 형성 | SNS 방식의 기록 기능을 통해 사용자가 소비를 재미있게 기록하도록 유도    |
| 소비 데이터 축적   | 사용자가 입력한 금액, 카테고리, 텍스트, 이미지를 기반으로 소비 데이터 저장 |
| AI 소비 분석    | 누적된 소비 데이터를 AI에 전달하여 소비 습관을 분석              |
| 소비 습관 피드백   | AI 분석 결과를 바탕으로 사용자의 소비 습관에 대한 개선방안 제공       |
| 금융상품 추천     | 외부 금융상품 API 데이터를 활용하여 사용자에게 적합한 상품 추천       |
| 제한된 공유      | 친구 관계인 사용자에게만 소비 로그 공개                      |

수정된 핵심 흐름은 다음과 같다.

```text
소비 기록 → 소비 데이터 누적 → AI 소비 분석 → 금융상품 추천
```

## 3. AI 소비 분석 기능 요구사항

AI 소비 분석 기능은 Flex-log의 필수 기능으로 정의한다.

사용자가 작성한 소비 로그 데이터를 바탕으로 월별 소비 금액, 카테고리별 소비 비율, 주요 소비 패턴을 정리한 뒤 AI API에 전달한다. AI는 해당 데이터를 기반으로 사용자의 소비 습관을 분석하고 개선방안을 생성한다.

| ID      | 요구사항              | 설명                                       | 우선순위 |
| ------- | ----------------- | ---------------------------------------- | ---- |
| F-AI-01 | 소비 데이터 요약         | 사용자의 월별 소비 금액과 카테고리별 소비 금액을 요약한다.        | 필수   |
| F-AI-02 | AI 분석 요청          | 요약된 소비 데이터를 AI API에 전달하여 소비 습관 분석을 요청한다. | 필수   |
| F-AI-03 | AI 분석 결과 제공       | AI가 생성한 소비 습관 분석 결과를 사용자에게 보여준다.         | 필수   |
| F-AI-04 | 개선방안 제공           | AI 분석 결과를 바탕으로 소비 습관 개선방안을 제공한다.         | 필수   |
| F-AI-05 | 분석 결과 저장          | AI 분석 결과를 DB에 저장하여 사용자가 다시 조회할 수 있도록 한다. | 필수   |
| F-AI-06 | 분석 실패 시 기본 피드백 제공 | AI API 호출 실패 시 규칙 기반 기본 피드백을 제공한다.       | 필수   |

AI 분석에 전달할 데이터 예시는 다음과 같다.

```text
- 분석 월
- 월별 총 소비 금액
- 카테고리별 소비 금액
- 카테고리별 소비 비율
- 소비 횟수가 많은 카테고리
- 가장 큰 지출 카테고리
- 최근 소비 로그 요약
```

AI 분석 결과 예시는 다음과 같다.

```text
- 이번 달 소비 요약
- 소비가 가장 많은 카테고리
- 과소비 가능성이 있는 항목
- 소비 습관 개선방안
- 추천 금융상품 유형
```

## 4. 금융상품 추천 기능 요구사항

금융상품 추천 기능은 Flex-log의 필수 기능으로 정의한다.

외부 금융상품 API를 활용하여 예금 또는 적금 상품 데이터를 가져오고, AI 소비 분석 결과를 바탕으로 사용자에게 적합한 상품을 추천한다.

| ID           | 요구사항           | 설명                                | 우선순위 |
| ------------ | -------------- | --------------------------------- | ---- |
| F-FINANCE-01 | 금융상품 API 호출    | 외부 금융상품 API를 호출하여 상품 데이터를 가져온다.   | 필수   |
| F-FINANCE-02 | 금융상품 데이터 저장    | API로 가져온 금융상품 데이터를 DB에 저장한다.      | 필수   |
| F-FINANCE-03 | 금융상품 목록 조회     | 사용자는 저장된 금융상품 목록을 조회할 수 있다.       | 필수   |
| F-FINANCE-04 | AI 분석 기반 상품 추천 | AI 소비 분석 결과를 바탕으로 적합한 금융상품을 추천한다. | 필수   |
| F-FINANCE-05 | 추천 사유 제공       | 추천된 금융상품이 왜 적합한지 사용자에게 설명한다.      | 필수   |
| F-FINANCE-06 | 상품 상세 정보 조회    | 사용자는 추천받은 금융상품의 상세 정보를 확인할 수 있다.  | 선택   |

상품 추천 기준은 다음과 같이 설정한다.

| 소비 분석 결과               | 추천 방향                |
| ---------------------- | -------------------- |
| 소비가 많고 저축 비율이 낮음       | 소액으로 시작 가능한 적금 상품 추천 |
| 매월 일정 금액을 남길 수 있음      | 정기적 납입이 가능한 적금 상품 추천 |
| 여유 자금이 있는 사용자          | 예금 상품 추천             |
| 단기 목표가 필요한 사용자         | 가입 기간이 짧은 상품 추천      |
| 안정적인 금융 습관 형성이 필요한 사용자 | 기본 금리와 조건이 단순한 상품 추천 |

## 5. AI 분석과 금융상품 추천의 연결 구조

AI 분석과 금융상품 추천은 분리된 기능이 아니라 하나의 흐름으로 연결한다.

```text
1. 사용자가 소비 로그를 작성한다.
2. 소비 로그 데이터가 누적된다.
3. 월별 소비 데이터와 카테고리별 소비 데이터를 계산한다.
4. 계산된 데이터를 AI API에 전달한다.
5. AI가 소비 습관을 분석한다.
6. 외부 금융상품 API에서 상품 데이터를 가져온다.
7. AI 분석 결과와 금융상품 데이터를 바탕으로 상품을 추천한다.
8. 사용자에게 추천 상품과 추천 사유를 제공한다.
```

## 8. AI API 실패 시 대체 전략

AI 분석은 필수 기능이지만, 외부 API를 사용하는 기능이므로 호출 실패 가능성을 고려해야 한다.

따라서 다음과 같은 대체 전략을 둔다.

```text
AI API 호출이 성공하면 AI 분석 결과를 제공한다.
AI API 호출이 실패하면 규칙 기반 기본 피드백을 제공한다.
```

규칙 기반 기본 피드백 예시는 다음과 같다.

```text
식비 비중이 전체 소비의 40% 이상이면 식비 절약 피드백 제공
카페 소비 횟수가 일정 기준 이상이면 카페 소비 조절 피드백 제공
쇼핑 소비가 전월 대비 증가하면 충동구매 주의 피드백 제공
```

이 방식은 AI 기능을 필수로 유지하면서도, 프로젝트 시연 중 API 오류가 발생했을 때 서비스 흐름이 끊기지 않도록 하기 위한 안전장치이다.

---

## 9. 금융상품 API 실패 시 대체 전략

금융상품 추천 역시 외부 API를 사용하는 기능이므로 API 호출 실패 가능성을 고려해야 한다.

```text
금융상품 API 호출이 성공하면 최신 상품 데이터를 저장하고 추천에 활용한다.
금융상품 API 호출이 실패하면 기존에 DB에 저장된 상품 데이터를 활용한다.
저장된 상품 데이터도 없는 경우 기본 안내 메시지를 제공한다.
```

이를 통해 외부 API 상태와 관계없이 사용자에게 최소한의 서비스 흐름을 제공할 수 있도록 한다.

## 10. 정리

요구사항 수정 결과, Flex-log의 핵심 기능은 다음과 같이 변경되었다.

```text
기존:
소비 기록 → 소비 분석 → 개선방안 제시

수정:
소비 기록 → AI 소비 분석 → 금융상품 추천
```

AI 분석과 금융상품 추천은 프로젝트의 차별성을 보여주는 핵심 기능이므로 필수 요구사항으로 포함한다.

다만 2주 프로젝트 기간을 고려하여 다음과 같이 최소 구현 기준을 설정한다.

```text
AI 분석:
소비 데이터를 요약하여 AI API에 전달하고 분석 결과를 저장한다.

금융상품 추천:
외부 금융상품 API에서 상품 데이터를 가져오고, AI 분석 결과를 바탕으로 추천 상품과 추천 사유를 제공한다.
```

이를 통해 Flex-log는 단순 소비 기록 서비스가 아니라, 사용자의 소비 데이터를 기반으로 금융 행동 개선과 금융상품 추천까지 연결하는 서비스로 정의된다.
